# A Ilha das 28 Palavras

Atividade online e interativa para alunos com dificuldades na leitura, baseada no **método das 28 palavras**.

O aluno percorre as 28 palavras como pedras numa ilha, guiado pelo **Cagarrito**, um cagarro que lê todas as instruções em voz alta.

## Passos de cada palavra
1. **Conhecer** – imagem, palavra escrita e leitura em voz alta.
2. **Sílabas** – tocar em cada sílaba, bater palmas e contar as sílabas.
3. **Montar** – ouvir a palavra e ordenar as sílabas.
4. **Descobrir** – reconhecer a palavra escrita entre outras.
5. **Palavras novas** – formar palavras novas só com sílabas já aprendidas.

Inclui também estrelas, jogo da memória, letra de imprensa ou manuscrita, voz lenta e uma área do professor (⚙️).

## Notas
- Tudo está num único ficheiro (`index.html`), sem dependências.
- A ordem das palavras pode ser alterada na lista `WORDS`, no início do código.
- A leitura em voz alta usa a voz em português do próprio dispositivo.
- O progresso fica guardado no navegador de cada aluno.
